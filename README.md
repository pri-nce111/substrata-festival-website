SUBSTRATA — An Underground Signal

An immersive underground electronic music festival website featuring interactive artist lineups, stage schedules, ticket sections, animations, and a modern dark user interface.

🎧 About the Project

SUBSTRATA is a creative website concept inspired by underground electronic music culture. It features a dark visual theme, glitch-inspired effects, animated elements, and a unique festival experience.

The concept represents a three-night electronic music festival where the venue location is revealed to ticket holders 48 hours before the event.

✨ Features

🎵 Interactive artist lineup with day-based filters

🎚️ Stage schedules for four music stages

🎟️ Festival ticket section

📍 Secret venue location concept

📧 Email notification form

🌑 Modern dark-themed user interface

⚡ Glitch effects, scanlines, and grain overlays

🎨 Animated visual elements and canvas backgrounds

📱 Responsive page structure

🔗 Navigation between website sections

🚀 How to Run the Project

Clone or download this repository.

Open the project folder in Visual Studio Code.

Make sure index.html, style.css, and script.js are in the correct locations.

Open index.html in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
