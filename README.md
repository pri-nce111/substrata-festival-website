SUBSTRATA — An Underground Signal
An immersive underground electronic music festival website featuring a bold visual identity, interactive artist lineup, stage schedules, ticket tiers, and secret-location notifications.
About the Project
SUBSTRATA is a creative festival website concept inspired by underground electronic music culture. It combines a dark aesthetic, glitch-inspired visuals, animated elements, and a responsive website layout to create an immersive digital experience.

The website presents a fictional three-night music festival where the venue location is revealed to ticket holders 48 hours before the event.
Features
- Immersive Homepage: Bold typography, live-signal indicators, and animated visual elements.
- Artist Lineup: Lineup section with day-based filters for Friday, Saturday, and Sunday.
- Stage Schedules: Dedicated section for four stages and their music schedules.
- Ticket Section: Area for festival ticket tiers.
- Secret Location: Festival concept with the venue revealed 48 hours before the event.
- Notification Form: Email input interface for location notifications.
- Interactive Navigation: Links to lineup, stages, information, and tickets.
- Visual Effects: Glitch-inspired styling, scanlines, grain overlays, and canvas-based visuals.
- Responsive Layout: Viewport configuration to support different screen sizes.
Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts (Anton, Space Mono, and Inter)
- HTML Canvas

Getting Started

3. Run the Website

Design Concept
The visual identity is based on underground electronic music culture:
- Dark backgrounds and high-contrast typography
- Bold, oversized headings
- Monospaced interface labels
- Glitch-inspired visual effects
- Animated signal and waveform concepts
- Minimal navigation with numbered sections
Project Goals
1. Build a visually distinctive festival website.
2. Practice HTML, CSS, and JavaScript development.
3. Explore animation and interactive interface design.
4. Create a portfolio-ready frontend project.
5. Establish a foundation for a more complete event website.
